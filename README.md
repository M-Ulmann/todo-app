# Todo App
Tento projekt zahrnuje typickou aplikaci na seznam, ve kterém si můžete nejen přidat či odebrat položku, ale také si ji upravit.

## Funkce stránky
- Přidání položky do seznamu
- Odstranění konkrétní položky ze seznamu
- Odstranění celého seznamu
- Úprava konkrétní položky v seznamu
